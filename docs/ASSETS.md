# Source images and attribution

Reviewed 2026-09-25. The current test build contains web-sized copies of all 5,860 images referenced by the local Tuxundoc chapters. `scripts/prepare_source_images.py` resizes and encodes images without cropping, watermark removal, mirroring or color changes; the original approximately 8 GB `tuxundoc/` archive remains local and unmodified. The generated copies in `public/source-images/` total 351,022,191 bytes. The Pages build is public during testing.

Each image has a stable `img-*` ID in `src/data/knowledge/images.json`, with original local path, chapter, Yuque chapter URL, source alt text and ordinal. `public/source-images/ready.json` records the converted count and failures. The 117 distinct images in reviewed clue cards have a direct mapping in `src/data/knowledge/source-photo-assets.json`; 121 cards share those images. A card's source image is chosen in `scripts/photo-review.json` only after visual inspection. All other source images remain browsable by chapter and do not automatically become selectable evidence.

The local metadata does not identify a verified author or redistribution license for each tutorial image. A Yuque URL provides traceability, **not** a license grant. The files are included in this public test build at the project owner's explicit direction; this document does not assert that the owner owns the underlying images or that reuse by others is permitted. The project's MIT code license does not apply to these images. Any source image whose rights need separate clearance can be removed without affecting inference, because scoring uses observation IDs and source facts rather than image counts.

The previous 24 Wikimedia Commons examples and their matching table were removed from the app and repository. Fonts and flags have their own license files under `public/fonts/` and `public/flags/`.
