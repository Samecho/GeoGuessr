# Source images and attribution

Reviewed 2026-09-25. The current test build contains web-sized copies of all 5,860 images referenced by the local Tuxundoc chapters. `scripts/prepare_source_images.py` resizes and encodes images without cropping, watermark removal, mirroring or color changes; the original approximately 8 GB `tuxundoc/` archive remains local and unmodified. The generated copies in `public/source-images/` total 351,022,191 bytes. The Pages build is public during testing.

Each image has a stable `img-*` ID in `src/data/knowledge/images.json`, with original local path, chapter, Yuque chapter URL, source alt text and ordinal. `public/source-images/ready.json` records the converted count and failures. The 324 distinct images used by reviewed clue cards have a direct mapping in `src/data/knowledge/source-photo-assets.json`; 304 cards use them. One source scene can support several atomic observations, but its picture is assigned only to a component it clearly depicts. Card images are recorded after visual inspection in `scripts/photo-review.json` or `scripts/focused-clues.tsv`. Some tutorial photos have a map inset; the card thumbnail can align left while Info keeps the original complete image. All other source images remain browsable by chapter and do not automatically become selectable evidence.

The project owner reports permission from the tutorial author for this project. The local archive does not identify an individual author or license for each image, so each asset records its original local path and chapter URL. The source permission reported by the owner does not grant reuse by others. The project's MIT code license does not apply to these images. Any source image whose rights need separate clearance can be removed without affecting inference, because scoring uses observation IDs and source facts rather than image counts.

The previous 24 Wikimedia Commons examples and their matching table were removed from the app and repository. Fonts and flags have their own license files under `public/fonts/` and `public/flags/`.
