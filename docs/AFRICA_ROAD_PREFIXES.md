# African road-number prefixes — source and estimate review

Reviewed 2026-09-26. These twelve text-only clues are for *a route number visibly printed on a road sign*, followed immediately (or after a space) by digits. R40 and RN1 are different prefixes. They do not use an arbitrary full road number to identify a place. Each `seenMultiplier` is an initial relative-likelihood estimate within the user's African custom scope, **not a measured sign frequency**. `absentMultiplier` stays neutral (1): not seeing a road number is not evidence against a country. No region multipliers were added because a generic prefix alone does not identify a province.

| Prefix | Places receiving support | Main source / constraint |
|---|---|---|
| R + digits | South Africa 8×, Senegal 7×, Ghana 5× | South African Department of Transport [TRH26](https://www.transport.gov.za/wp-content/uploads/2023/02/TRH26-RCAM.pdf) identifies R routes; Senegal [FERA](https://fera.sn/services-aux-usagers/repartition-du-reseau-routier/) identifies regional R routes; Ghana [Ministry of Roads and Highways](https://mrh.gov.gh/works/big-push-projects/design-build-for-the-dualization-of-adenta-dodowa-road-r40-22km/) identifies R40. Shared, not South African exclusive. |
| A + digits | Botswana 5×, Kenya 5×, Nigeria 4×, Namibia 3×, Tunisia 3× | Botswana [Road Maintenance Manual](https://www.vegvesen.no/globalassets/om-oss/om-organisasjonen/internasjonal-virksomhet/botswana-road-maintenance-manual-part-a.pdf) lists A1–A3; Kenya [Roads Act](https://www.roads.go.ke/sites/default/files/2024-12/THE%20KENYA%20ROADS%20ACT%202007_No%202%20of%202007.pdf) class A; Nigeria [Federal Ministry of Works](https://hdmi.fmw.gov.ng/about-us) lists A routes; Namibian [environment ministry-hosted map](https://eia.meft.gov.na/screening/5869_site_map.pdf) labels A1; Tunisian [ministry atlas](https://www.mehat.gov.tn/wp-content/uploads/2024/02/AtlasBenArousFr.pdf) mentions A1 motorway. |
| B + digits | Botswana 4×, Kenya 4×, Namibia 5× | Botswana [government DailyNews](https://dailynews.gov.bw/common_up/dailynews/dailynews_pdf/02-05-2023_11-54-36_1683021276_dailynews_pdf.pdf) names B111; Kenya Roads Act class B; Namibian [Roads Authority annual report](https://ra.org.na/cms/Lists/Annual%20Reports/Attachments/8/Annual_Report_2019_2020.pdf) names B1. |
| C + digits | Namibia 6×, Kenya 4× | Local tutorial `tuxundoc/非洲/namibia/index.html` explicitly mentions C20, C22, C23, C46; Kenya Roads Act class C. |
| D + digits | Senegal 5×, Kenya 3×, Namibia 2×, South Africa 2×, Eswatini 2× | Senegal FERA departmental D; Kenya Roads Act class D; Namibia [Roads Authority](https://ra.org.na/register) describes district DR (D-only road signs need further visual confirmation); South African TRH26 says provincial D routes exist but are minor; Eswatini [government road list](https://gov.sz/images/CabinetMinisters/Roads-under-rehabilitation-1.pdf) lists D8. The Namibia support is deliberately modest because official documents often write DR rather than D. |
| MR + digits | Eswatini 10×, Namibia 2× | Eswatini [government transport account](https://40years.gov.sz/how-public-works-and-transport-helped-build-a-more-connected-mobile-and-competitive-eswatini/) describes MR3; Namibia [Roads Authority newsletter](https://ra.org.na/assets/uploads/newsletters/newsletters_20260309_074631_b0d4f393fc.pdf) uses MR120 as an administrative main-road label. Namibian roadside visibility has not been verified; its 2× is provisional. |
| N + digits | South Africa 6×, Senegal 5×, Ghana 5× | South African TRH26, Senegal FERA, [Ghana Highway Authority route list](https://highways.gov.gh/road_net). |
| M + digits | South Africa 4× | South African TRH26 explicitly identifies metropolitan M routes. Excludes MR+digits. |
| RN + digits | Réunion 8×, Tunisia 7× | [Région Réunion RN1](https://regionreunion.com/actualite/toute-l-actualite/article/rn1-creation-d-une-voie-verte-au-droit-du-chemin-des-anglais-entre-la-rn1001-et-la-rue-lumumba). Tunisian [Ministry of Equipment](https://www.mehat.gov.tn/fr/principaux-secteurs/ponts-et-chaussees/projets-routiers-programmes/) also uses RN. Excludes plain R and N. |
| RD + digits | Réunion 8× | [Département de La Réunion RD41](https://www.departement974.fr/routes). Excludes plain R and D. |
| RR + digits | Tunisia 10× | [Tunisian public procurement authority](https://www.marchespublics.gov.tn/fr/projets-annuels/P2026-141924) identifies RR91/122. Excludes plain R. |
| RL + digits | Tunisia 10× | Same public procurement source identifies RL650/889. |

The local tutorial is also used for `tuxundoc/非洲/botswana/index.html` (A-road examples), `tuxundoc/非洲/kenya/index.html` (A109), and `tuxundoc/非洲/south-africa/index.html` (R360). Sources establish route-number systems, **not** the statistical probability that a random GeoGuessr scene displays a numbered road sign. Unlisted countries remain neutral, not impossible. Prefix cards contain no image because no suitable route-sign photo was verified for redistribution in this pass. Namibia uses DR numbers administratively, but I did not add a DR card because I could not verify that this format is presented on roadside signs.
