# Local Tuxundoc review record

Updated 2026-09-25. `tuxundoc/index.html` links 133 chapter folders. The importer reads each linked HTML file, headings, paragraphs, emphasis, metadata and image paths in small chapter batches. It records 8,466 source blocks, 8,602 parsed claims, 5,102 raw qualitative estimates and 5,860 image references. One chapter lacks `document.lake`; its HTML was still processed. The approximately 8 GB originals are ignored by Git and unchanged.

Raw extraction is deliberately separated from the playable library. The previous UI exposed thousands of highlighted prose fragments as if they were polished observations. The reviewed playable library now contains 488 concise bilingual visual clues, including 286 focused paragraph review rows for Canada and the 18 African chapters. The 5,317 raw phrase IDs without a playable mapping remain in the audit and are not scored. Another 51 proposed phrases in the curation table do not currently match an extracted phrase; `curation-missing.json` records them for follow-up. This is a substantial first curation pass, not a claim that all chapter prose has been semantically reviewed.

A source paragraph's nearby word “没有” or “唯一” often refers to another property, a single road, a specific year, or a subregion. `estimate-context-review.json` corrects 68 parsed extreme estimates after checking context. Twenty-one other extreme estimates are withheld from scoring and listed in `estimate-context-audit.json`. Two joint evidence rules with matching observed features remain active; a third was withheld because its source describes a **short** front plate while the available observation only says **a** front plate.

All 5,860 original source images were converted to web-sized copies for the user-directed public Pages test. Of the playable clues, 325 have a visually checked image choice; 163 stay text-only. The full image archive can be browsed by chapter without changing scores. Source URLs and image IDs establish traceability; the owner reports permission from the tutorial author, while individual image license metadata is absent in the archive. See [ASSETS.md](ASSETS.md).
